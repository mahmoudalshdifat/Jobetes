# Design Tokens

## Colors

| Token | Hex | Tailwind class examples | CSS Variable |
|-------|-----|------------------------|--------------|
| Brand Primary | `#1B4D7A` | `bg-brand-primary`, `text-brand-primary` | `--color-brand-primary` |
| Brand Secondary | `#2C8C9E` | `bg-brand-secondary`, `text-brand-secondary` | `--color-brand-secondary` |
| Surface Warm | `#F8F4EE` | `bg-surface-warm`, `text-surface-warm` | `--color-surface-warm` |
| Surface White | `#FFFFFF` | `bg-surface-white`, `text-surface-white` | `--color-surface-white` |
| Ink Strong | `#0F1B2D` | `text-ink-strong` | `--color-ink-strong` |
| Ink Soft | `#4A5568` | `text-ink-soft` | `--color-ink-soft` |
| Accent Olive | `#6B7F4E` | `bg-accent-olive`, `text-accent-olive` | `--color-accent-olive` |
| Accent Copper | `#B8654A` | `bg-accent-copper`, `text-accent-copper` | `--color-accent-copper` |

## Typography

- Primary font stack: `Inter`, `IBM Plex Sans Arabic`, `system-ui`, `-apple-system`, `Segoe UI`, `sans-serif`
- Arabic font stack: `IBM Plex Sans Arabic`, `Noto Naskh Arabic`, `system-ui`, `sans-serif`
- Tailwind classes: `font-sans`, `font-arabic`

## Spacing & Layout

- Max reading width: `max-w-reading` (maps to `40rem`)
- Extra large border radius: `rounded-4xl` (maps to `2rem`)
