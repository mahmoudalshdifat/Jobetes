# Lessons — Lernen nach jedem Chat-Run

Ziel: Nach jedem Chat-Run bekommst du hier ein **Jupyter Notebook**, das dir
Schritt für Schritt erklärt, was passiert ist — in einfacher Sprache, mit Code
zum Selbst-Ausprobieren.

## Notebook öffnen

In VS Code (Codespace): einfach auf die `.ipynb`-Datei klicken. VS Code öffnet
das Notebook direkt. Oben rechts den Python-Kernel auswählen (Python 3.12).

## Zellen ausführen

- **Shift+Enter** — Zelle ausführen, zur nächsten springen
- **Ctrl+Enter** — Zelle ausführen, bleiben

## Aufbau jeder Lesson

1. **Was war das Ziel?** — was sollte gemacht werden
2. **Was wurde gemacht?** — welche Dateien wurden geändert
3. **Wie funktioniert das?** — die Idee dahinter, mit Mini-Beispielen
4. **Spielwiese** — Code-Zellen zum Selbst-Verändern
5. **Begriffe** — neue Wörter erklärt
